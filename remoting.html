How to Verify in chrome://media-router-internals
  • GMC Cast button or video.remote.prompt() (Remote Playback / Remoting without Fullscreen): Play the video first so Chrome's Media Session registers it in GMC, then select a remoting-capable receiver from the GMC media card. The route's media source will start with remote-playback:media-element?tab_id=...&video_codec=...&audio_codec=....
  • Toolbar Cast icon → Cast tab (Tab Mirroring & Fullscreen Remoting): Selecting a receiver from the browser toolbar Cast dialog starts tab mirroring (urn:x-org.chromium.media:source:tab:...). Entering fullscreen while playing switches the session to Media Remoting after ~5 seconds on supported receivers, and falls back to tab mirroring if switched to a receiver that does not support remoting.
  • Why this differs from Vimeo / YouTube: Sites that load the Cast Web Sender SDK register a default PresentationRequest (cast:<AppID>), which launches a native receiver web app instead of Chrome Media Remoting. This page intentionally does not register a PresentationRequest.
